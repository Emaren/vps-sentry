## One ordinary login, without one unsafe blanket approval

1. The original authenticated macOS owner session (UID501) is the **operator-present authentication context**. A Mac account name alone, SSH key alone, GitHub comment, browser cookie or `sudo` success is not an owner permit. The original WE2 Factory one-use owner approval issuer is a **separately authenticated original source**, and must be source-reviewed before it can issue storage-specific capabilities. No export/unlock/passphrase recovery of the existing encrypted V6 Ed25519 key.
2. Enrollment is one original-owner event for **an exact stable source class**. It may permit routine bounded **L1 only** during an active, revocable owner session, never a file-name pattern or old L4/L5. If issuer enrollment is absent, current result is `OWNER_CAPABILITY_NOT_ENROLLED`; plan/scan remains read-only.
3. Every actual mutation must carry an original-verifiable **one-use scoped capability** naming action, purpose, original issuer identity, exact installed controller source SHA, canonical project/host, filesystem UUID, dev/inode/size CAS, source producer class, expiration (at most 15 min), random nonce, immutable receipt ledger and replay-rejection. A one-time class approval can replace recurring *human deliberation*, not exact fresh per-object checks. No long-lived root credential, no automatic passphrase, no new auth service or root daemon.
4. Before execution, the original installed controller verifies the credential **with its existing pinned trust**, then rechecks source/head/producer, original UID/mount, hardlink/symlink/submount, active service/FD, current BAE+two-hot protection, 3030/3033 recovery, finance/evidence exclusions, and stable object CAS. Any error or missing live evidence -> HOLD; the checker is not allowed to silently replace the target.
5. Execute at most one object per transaction under the existing root maintainer's lock, in root-owned same-filesystem isolation. Durable tamper-evident receipt: class source SHA, one-use grant id, object CAS, original scan timestamp+coverage, pre/post *same filesystem* ordinary free bytes, cause/result, deleted object count, error/failure recovery. `gross_allocated_bytes` is **never** used as `physical_reclaimed_bytes`. Failing/stale/noncurrent operation returns **no deletion** and one concise owner exception.

## Hard denials, independently test before enrollment

Closed/absent original Mac owner session; wrong UID/host, changed controller source hash, missing independent Factory T10/source evidence, mismatched BUILD_ID or artifact, absent or replayed one-use grant, expired nonce, changed dev/inode/size/UUID or active FD, source/protected original, current BAE/HOT1/HOT2, appearance/social, 3030/3033, database/financial/custody, unavailable Intel receiver/reserve, signed backup/sole restoration, or historical L4 NO/L5 NEVER DELETE. Mac login **cannot** authorize these by itself. No UI button, chat message or PR review can mint the signature.
